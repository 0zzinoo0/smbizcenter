중소기업비지니스센터 운영용 V2 설정 안내

1. 관리자 주소
   https://내사이트주소/admin/

2. Netlify 환경변수 (Project configuration → Environment variables)
   필수 관리자 설정
   - ADMIN_USER: 관리자 아이디
   - ADMIN_PASSWORD: 강한 비밀번호
   - ADMIN_SECRET: 임의의 긴 영문/숫자 문자열(32자 이상 권장)

   GA4 방문 통계
   - GA4_MEASUREMENT_ID: G-로 시작하는 측정 ID

   Google Ads 전환 추적
   - GOOGLE_ADS_ID: AW-로 시작하는 ID
   - GOOGLE_ADS_CONVERSION_LABEL: 전환 액션 라벨
   - GOOGLE_ADS_CONVERSION_VALUE: 1 (선택)
   - GOOGLE_ADS_CURRENCY: KRW (선택)

   상담 신청 이메일 알림(Resend 사용)
   - RESEND_API_KEY: Resend API 키
   - LEAD_NOTIFY_EMAIL: 알림을 받을 이메일
   - LEAD_FROM_EMAIL: 인증된 발신 이메일

3. 상담 신청 확인
   Netlify → Forms → consulting

4. 동작
   - 홈페이지 콘텐츠는 관리자에서 저장하면 Netlify Blobs에 반영됩니다.
   - 상담 제출 후 완료 페이지에서 GA4 generate_lead와 Google Ads conversion 이벤트가 실행됩니다.
   - 이메일 환경변수가 없더라도 상담 접수는 정상 저장됩니다. 이메일 알림만 생략됩니다.

5. 배포 후 테스트
   - 관리자 로그인
   - 메인 제목 한 글자 수정 후 저장/홈페이지 반영 확인
   - 상담 신청 테스트/Forms 저장 확인
   - GA4 실시간 보고서 확인
   - Google Ads 진단에서 전환 태그 확인
